**Why this family exists.** The catalogue says where open data is and whether it is real (L0–L3).
A geoscientist still spends hours turning a download into a working project: coordinate system,
vertical datum, depth reference, units, null values, log names, time or depth. A starter project is
that work done once, by a recipe, with every decision written down, delivered in the form each
application opens natively. The analogues the planner named: Microsoft Planetary Computer (a STAC
catalogue with one ready notebook per dataset), Pangeo Forge recipes, Hugging Face Datasets (one
dataset, loaders for every framework), nf-core references (reference genomes pre-indexed per tool),
Geofabrik (free extracts, paid curation), and in this field dGB's F3 Demo and Equinor's Drogon.

```text

```

**Family rules.**

- **R-T1 Generated, never hand-made.** Every artefact a person downloads from a pack was written
  by a recipe run that the pack document names (recipe id, tool versions, input digests). A
  hand-edited artefact is a defect: the pack is withdrawn, not patched. Reason: the F3 Demo is
  itself a hand-curated project nobody can regenerate; version rot in OpendTect and ResInsight
  would make hand-made packs stale within months.
- **R-T2 Through the door.** A target is reached through the application's own binding or
  Python API, or as a standard file plus an import script written against that API. No pack ever
  contains a decoded or synthesised application project store (Ophiolite R-C1, D69). Reading dGB's
  F3 survey through odbind is through the door; parsing its directory is through the wall.
- **R-T3 The decision log is part of the pack.** Horizontal CRS and the transformation used,
  vertical datum, depth reference (KB, RT or MSL) per well, measured versus true vertical depth,
  units per quantity, null conventions, time or depth domain and any velocity used, log name
  mapping. Each line names its source: the publisher's statement, the data itself, or "chosen by
  us, because …". A pack without a complete log does not publish (E40 validity test).
- **R-T4 Licence flows down.** A pack's licence is computed from its inputs, never typed: one
  share-alike input makes the pack share-alike; attribution lines are always written; an input
  with `redistribution: unknown` or `restricted` never enters a pack. A pack's artefacts live in
  the mirror under E07 custody with the same takedown route.
- **R-T5 An oracle that is not our own tool.** The first pack is judged against dGB's own F3
  survey read through odbind; later packs against values the publisher states or a second
  independent reader (segyio, lasio) gives. Parity with Ophiolite's readers is a second check and
  a mismatch blocks.
- **R-T6 Free first, measured.** Packs are free to download. Whether anyone pays, and for what
  (currency, support, a target nobody else builds), is an owner decision opened only on evidence
  of use (OSD-D23). No paywall, account or key appears in this family.
- **R-T7 One dataset proves the chain before the next is chosen.** E42 (F3) must publish before
  E44 picks further datasets; the owner chooses the blocks (OSD-D24).
