**3. Design objections and concrete alternatives**

- **Schema bump is mandatory.** File entries reject additional properties (`schema/verification.schema.json:43`); optional `publisher_checksum` still changes the contract. Require verification/4, freeze /3, test old documents against /4, announce the change in the PR title, and claim the frozen-schema path.
- **Checksum comparison lacks an algorithm contract.** Current hashing is SHA-256 (`src/osd/verify.py:290`). Specify algorithm plus digest, supported algorithms, malformed/unsupported handling, and comparison against the corresponding digest computed from the same stream; retain SHA-256 for existing consumers.
- **“Every machine-readable dataset reaches L2” is impossible under existing guards.** Reachability, licence capture, robots restrictions and budget remain prerequisites (`src/osd/verify.py:467`, `:486`). Promise supported listings are attempted and failures explained.
- **A files-check reason cannot explain every L1.** Files may pass while licence capture fails (`src/osd/verify.py:476`, `:486`). Report the actual failing/skipped L2 checks, including licence failures, listing errors and sample-selection failures.
- **Generated exports need explicit selection and completeness rules.** Specify bounded query parameters, pagination/truncation handling and sample coverage; metadata or an error response must not become a successfully checksummed dataset asset.
- **The required PR verify comment will not run automatically.** This lane changes neither trigger path (`.github/workflows/verify.yml:10`). Use the existing workflow’s branch dispatch and attach its run/results to the PR; keep network success observational under ENGINEERING’s outage policy.

**4. Acceptance weaknesses**

- **“Eight of ten” permits untested readers and missing policies.** Derive the target set from records; assert every manifest record has a policy. Existing `tests/test_verify.py:324` checks only the reverse direction and survives deletion of a policy while three remain.
- **One fixture per reader does not prove correct selection.** Assert exact asset URLs, names, sizes and excluded metadata links. Mutating a reader to return a landing page must fail.

- **Skip-text mutations alone do not prove guards.** Assert forbidden fetches never occur, partial files are absent and shared budget is respected.
